# MediClaim AI Frontend

Next.js 15 TypeScript frontend for MediClaim AI, India's first Clinical Documentation Standardization Platform.

## Stack

- Next.js 15
- TypeScript
- TailwindCSS
- Framer Motion
- Recharts
- React Query
- Auth.js
- shadcn/ui-style primitives

## Run

1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Build production app: `npm run build`
